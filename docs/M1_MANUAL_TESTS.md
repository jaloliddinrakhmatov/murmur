# M1 Manual Test Procedure

For a human tester on a Mac. Automated checks cannot press physical keys, observe another app's text field, or grant TCC permissions, so these steps verify what the smoke test cannot. Record each result in the table at the end and attach it to [M1_VERIFICATION.md](M1_VERIFICATION.md).

## Setup (5 minutes)

1. Follow the setup in [`README.md`](../README.md) (`npm install`, `npm run build:native`, `npm run build`, `npm start`).
2. On first launch the Murmur window opens on **Setup**:
   - Permissions: click **Allow microphone** (system prompt) and **Allow** for Accessibility (System Settings opens; enable Electron/Murmur).
   - Transcription: choose a provider and paste an API key, or choose `whisper.cpp` with a running local server.
   - Shortcut: keep `ctrl+opt+space`; press it and confirm **detected** appears.
3. Open TextEdit with a new document.

Expected states on the Capsule (bottom centre): thin resting bar → **Listening** with level bars → **Writing…** → **Done** (green) → resting.

## Tests

| #   | Test                         | Steps                                                                                                                                         | Expected                                                                                                                                                                                 |

| 1   | Hold-to-talk                 | In TextEdit, hold `ctrl+opt+space`, say "Hello world comma this is a test", release.                                                          | Capsule shows Listening while held; "Hello world, this is a test." appears at the caret within ~2 s (cloud) ; History lists it as **inserted**.                                          |
| 2   | Shortcut release timing      | Tap the shortcut for < 0.3 s without speaking.                                                                                                | Nothing is inserted; nothing appears in History.                                                                                                                                         |
| 3   | Hands-free                   | Double-tap the shortcut, speak two sentences, press the shortcut once.                                                                        | Capsule shows **Hands-free** with ✕; text inserted after the final press. Pressing ✕ or Esc instead inserts nothing.                                                                     |
| 4   | Microphone recording         | While holding the shortcut, speak louder and softer.                                                                                          | Level bars move with your voice; the macOS orange mic indicator is on only while recording.                                                                                              |
| 5   | TextEdit insertion           | Type "before " then dictate "after".                                                                                                          | Result is "before After." at the caret; existing text untouched; ⌘Z removes only the dictated text.                                                                                      |
| 6   | Browser input                | In Safari and Chrome, focus a textarea (e.g. a search box or a form) and dictate.                                                             | Text inserted at the caret. Record per browser.                                                                                                                                          |

| 8   | Clipboard not overwritten    | Dictate; within 0.3 s of the text appearing copy "NEWER"; wait 1 s; ⌘V.                                                                       | "NEWER" is pasted (Murmur did not restore over it).                                                                                                                                      |
| 9   | Password field rejection     | Focus a native password field (System Settings → Users & Groups → Change Password, or Keychain Access unlock) and dictate.                    | Capsule: "Password field — not inserted (saved in History)"; nothing typed; clipboard unchanged; History row **rejected**.                                                               |

Without it, record the observed behavior (M0 noted the secure-input signal may not cover web fields).                                         |
